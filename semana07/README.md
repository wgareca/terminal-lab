# Semana 07 - Bash: loops, arrays y funciones

Gestor de tareas interactivo con persistencia en archivo CSV y estructura modular en `lib/`.

## Archivos
- `gestor-tareas.sh` - menu principal en bucle
- `lib/tareas.sh` - funciones de alta, listado, completo y eliminacion
- `lib/validaciones.sh` - validacion de opciones, descripciones e IDs
- `datos/tareas.csv` - almacenamiento persistente en CSV

## Ejecucion
./gestor-tareas.sh
