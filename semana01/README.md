# semana 01 - Fundamentos y sistemas de archivos

## Que hace
recorre seis directorios del sistema (/etc, /var, /home, /bin, /tmp, y /proc), explica su funcion y lista sus primeros elementos.

## Archivos
- `explorar-sistema.sh`- script principal
- `salida-ejemplo.txt`- salida guardada del script

## Como se ejecuta
```bash
chmod +x explorar-sistema.sh
./explorar-sistema.sh
```
## Que se aprendio
- Como funciona la jerarquia de directorios en Linux desde la raiz`/`.
- La diferencia entre directorios reales y sistemas virtuales como `/proc`.
- Como crear un script en Bash, darle permisos (`chmod +x`) y ejecutarlo con `./`.
- Como guardar la salida de un comando en un archivo usando `>`.
